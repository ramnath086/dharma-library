# Dharma Library — Flutter app

Platform folders here are intentionally minimal (manifest, Info.plist, Gradle
config, deep-link + audio permissions). On first checkout run:

```bash
cd app
flutter create . --platforms=android,ios --org org.dharmalibrary --project-name dharma_library
```

`flutter create .` regenerates the boilerplate files (icons, LaunchScreen,
Runner.xcodeproj, gradle wrapper jar) **without overwriting** the files
committed here. Then:

```bash
flutter pub get
flutter gen-l10n
flutter test
flutter run --dart-define-from-file=../env.json     # or --dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...
```

Without `SUPABASE_URL`/`SUPABASE_ANON_KEY` the app runs in **bundle mode**:
content comes from `assets/bundles/bhagavata-purana.json` (generated by
`scripts/export_bundle.py`), bookmarks/progress stay on-device, and Ask/Sign-in
are disabled.
